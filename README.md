## 作品について

大原三寂の一人寂然（藤原頼業）の家集で、十重禁戒・十法界などを詠んだ釈教歌や今様を収める。ここの本文は国立国会図書館所蔵の珍書同好会刊本（大正五年）で、冒頭に刊行者の解説、末尾に勅撰集に入った寂然の歌を集めた附録がある。

## 本文の作り方

国立国会図書館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。影印本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（1ファイル）。 |
| `uta.tsv` | 作中歌の一覧（番号・段落ID・本文・読み・詠み手・種別・原本のコマ）。 |
| `ndl-yuishinbo-shu.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。 |

段落ID（例: `ndl-yuishinbo-shu-0001`）は、本文を直しても変わりません。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/yuishinbo-shu/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、底本と照らして確かめてから取り込みます。
